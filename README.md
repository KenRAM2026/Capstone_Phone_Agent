# Automated Conversational Phone Agent for Credit Card Servicing
VCU Capstone Project sponsored by Capital One
----------------------------------------------
Description: A standalone AI designed to handle inbound calls without human intervention. This system authenticates callers, identifies intents, resolves requests (e.g., disputes, payments, balance inquiries) against mocked APIs, and provides natural speech responses. Key components include speech-to-speech pipelines, LLM reasoning cores, compliance guardrails, and escalation logic, with metrics focused on containment and accuracy.
